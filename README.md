# 考研目标学习站

一个适合 GitHub Pages 发布的静态考研学习网站。用户可以填写院校、专业、考试年份和官方来源链接，粘贴或上传学校官网/研招网专业目录文本，半自动识别英语、数学/综合和专业课科目，并生成可打印的个性化学习报告。

## 功能

- 倒计时默认指向 2026-12-19，可在页面里修改。
- 支持保存多个院校/专业目标方案。
- 识别 201 英语一、204 英语二、301 数学一、302 数学二、303 数学三、396 经济类综合能力。
- 可手动确认不考数学、英语科目和自命题专业课。
- 支持上传 PDF 并在浏览器内提取文字，失败时可粘贴目录文本。
- 根据科目生成学习模块、资料清单和可打印 PDF 报告。
- 附带通用讲义 PDF：`assets/kaoyan-study-guide.pdf`。

## 使用

直接打开 `index.html`，或通过任意静态服务器运行：

```bash
npx serve .
```

## 发布到 GitHub Pages

默认目标仓库是 `MIST-BEN/kaoyan-study-site`。

如果已经安装并登录 GitHub CLI：

```powershell
.\publish-to-github.ps1
```

如果没有 GitHub CLI：

1. 在 GitHub 新建公开空仓库 `kaoyan-study-site`。
2. 在本目录运行 `git push -u origin main`。
3. 打开仓库 `Settings > Pages`，来源选择 `main` 分支根目录。

## 来源原则

所有考试科目、参考书、考试大纲和招生政策，最终以招生单位官网、研究生院/研招办公告、中国研究生招生信息网公布内容为准。本网站只做资料整理和学习计划辅助。
